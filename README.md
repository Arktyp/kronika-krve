# Kronika krve – webová verze

Aplikace na postavy pro Vampire: The Masquerade (V5 + V20).
Každý hráč se přihlásí a vidí jen své postavy, Vypravěč vidí všechny.

* `index.html` – celá aplikace (jeden soubor)
* `firestore.rules` – pravidla databáze (kdo co smí číst a zapisovat)

Nová verze = nahraj nový `index.html` (Add file → Upload files → Commit).
Data jsou ve Firebase, výměna souboru na ně nesahá.
